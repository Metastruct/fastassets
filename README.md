# srvassets
Assets for the various addons we use, equivalent of fastaddons but for assets.

### Adding an asset

Please follow source's directory format for storing the files, with the addons being in their own folders inside a master `/metastruct/` folder.

Example:
- `materials/metastruct/my_meta_weapon/`
- `sounds/metastruct/sauna_sounds/`
- `models/metastruct/cheeseburger/`
